# 교내 연구진흥사업 만족도 설문 (Google 계정 로그인 + 시트에서 문구 수정)

- 학교 Google 계정(`yonsei.ac.kr`)으로 로그인한 사람만 응답할 수 있고, 한 계정당 응답 1건입니다.
- **문항과 안내문은 구글 시트의 탭에 적혀 있습니다.** 코드를 몰라도 엑셀 칸을 고치듯 수정하면 설문 화면에 반영됩니다.
- 응답은 같은 시트의 `응답` 탭에 쌓입니다.

파일은 3개입니다: `Code.gs`(서버), `Seed.gs`(샘플 문항), `Index.html`(설문 화면). 이 파일들은 처음 설치할 때만 씁니다.

---

## 1. 설치 (약 10분, 담당자 1명이 한 번만)

1. **학교 Google 계정**으로 새 구글 시트를 만듭니다. 이름 예: `만족도 설문 응답`
2. 메뉴 **확장 프로그램 → Apps Script**를 엽니다.
3. 기본 파일 `Code.gs`의 내용을 모두 지우고 이 폴더의 `Code.gs` 내용을 붙여넣습니다.
4. 왼쪽 파일 목록의 **+ → 스크립트**를 눌러 이름을 `Seed`로 만들고, 이 폴더의 `Seed.gs` 내용을 붙여넣습니다.
5. **+ → HTML**을 눌러 이름을 `Index`로 만들고, 이 폴더의 `Index.html` 내용을 붙여넣습니다.
6. 위쪽 **저장(디스크 아이콘)**을 누릅니다.
7. 구글 시트 화면으로 돌아와 **페이지를 새로고침**합니다. 상단 메뉴에 **설문 관리**가 생깁니다.
8. **설문 관리 → ① 샘플 문항 불러오기 (처음 한 번)**을 누릅니다. 처음에는 권한 승인 창이 뜨니 본인 계정으로 허용하세요.
   시트에 `안내문구`, `공통질문`, `사업목록`, `사업안내`, `사업별질문`, `마무리질문` 탭이 생기고 PDF 문항이 채워집니다.
9. Apps Script 화면에서 **배포 → 새 배포 → 유형: 웹 앱**
   - **다음 사용자 인증정보로 실행: 나**
   - **액세스 권한이 있는 사용자: Google 계정이 있는 모든 사용자**
     ("yonsei.ac.kr 내 사용자"로 제한하면 개인 계정은 구글의 차단 화면만 보고 계정을 바꿀 방법이 없습니다. "모든 사용자"(로그인 없이 접속)는 선택하지 마세요.)
   - **배포**를 누르고 나오는 **웹 앱 URL**이 응답자에게 보낼 설문 링크입니다. (시트 메뉴 **④ 설문 링크 보기**에서도 확인할 수 있습니다.)

> 응답 허용 도메인은 `Code.gs` 맨 위 `ALLOWED_DOMAINS`에 `yonsei.ac.kr`로 설정되어 있습니다. 링크는 구글 계정이 있으면 누구나 열 수 있지만, **학교 계정이 아니면 문항은 보이지 않고 로그인 안내 화면만 나오며 응답은 저장되지 않습니다.**

## 2. 링크를 두 가지로 나눠 쓰기
- **응답자(전임교원)**: 웹 앱 URL만 공유합니다. 시트 접근 권한은 필요 없습니다.
- **편집자·소유자**: 구글 시트를 공유합니다. 문구 수정도, 결과 확인도 이 시트에서 합니다.

---

## 3. 문구 수정하는 법 (코드를 열 필요 없음)

시트 아래쪽 탭에서 **칸을 직접 고치면 됩니다.** 각 탭 맨 위 칸(A1)을 누르면 사용 설명 메모가 나옵니다.
수정 내용은 **5분 안에 자동으로** 설문에 반영되고, 바로 보고 싶으면 **설문 관리 → ③ 변경 내용 바로 반영하기**를 누르세요.

| 고치고 싶은 것 | 어느 탭 | 방법 |
|---|---|---|
| 설문 제목, 인사말, 조사기간, 맺음말 등 | `안내문구` | **항목 하나가 한 줄**입니다. 가운데 "내용" 칸 하나만 고치면 됩니다. 칸 안에서 줄바꿈은 `Alt+Enter`(맥 `Option+Enter`), **문단은 빈 줄**(Alt+Enter 두 번)로 나눕니다. 오른쪽 "작성 안내"에 항목별 설명이 있습니다 |
| 공통질문 문구·보기 | `공통질문` | 한 줄이 한 문항입니다. **보기는 "보기" 칸 하나에 한 줄에 하나씩** 적습니다 (Alt+Enter로 줄바꿈) |
| "기타 직접 입력" 칸 | 보기 칸 | 직접 입력창을 열 보기 앞에 `[직접입력]` 을 붙입니다. 예: `[직접입력] 기타(직접 입력)` |
| 질문 추가 | `공통질문` 등 | 마지막 줄 아래에 새로 적습니다. ID는 자동으로 채워집니다 |
| 객관식 ↔ 복수선택 ↔ 서술형 | `유형` | 칸을 눌러 목록에서 고릅니다 |
| 필수 해제 | `필수` | `아니오`로 바꿉니다 |
| 최대 N개 / 정확히 N개 선택 | `최대 선택 수` / `정확히 선택 수` | 복수선택 문항에만 숫자를 적습니다 |
| 사업 이름·홈페이지 링크 | `사업목록` | 이름과 링크를 고칩니다. 링크는 `https://`로 시작해야 합니다 |
| 사업을 설문에서 빼기 | `사업목록`의 `사용` | `아니오`로 바꿉니다 |
| 사업 안내문(목적·대상·금액) | `사업안내` | **소제목 하나가 한 줄**이고, "내용" 칸 하나에 그 소제목의 문장들을 줄바꿈으로 나눠 적습니다 |
| 빨간 글씨·들여쓰기 | 내용 칸의 줄 앞 | 줄 앞에 `[강조]` 를 붙이면 빨간 글씨, `[들여쓰기]` 를 붙이면 들여쓰기입니다 |
| 표 넣기 | `사업안내` | 같은 소제목으로 줄을 하나 더 만들고 **종류를 `표`**로 바꿉니다. 내용 칸의 첫 줄은 표 머리, 다음 줄부터는 표 행이며 **칸은 `|` 로 나눕니다**. 표 칸 앞에 `[강조]` 를 붙이면 빨간 글씨 |
| 선택한 사업마다 나오는 질문 | `사업별질문` | `사업번호`가 `전체`이면 모든 사업에, `3-1` 또는 `3-1,3-2`로 적으면 그 사업에만 나옵니다 |
| 마무리 질문 | `마무리질문` | 공통질문과 같은 방법입니다. 보기에 `[사업목록]` 이라고 한 줄 적으면 사업 이름이 보기로 자동 채워집니다 |

**수정한 뒤에는 꼭 한 번 점검하세요.** **설문 관리 → ② 변경 내용 점검**을 누르면, 보기가 모자라거나 유형을 잘못 쓴 줄을 알려 줍니다. (문제가 있는 문항은 설문에 나오지 않습니다.)

### 수정할 때 지켜 주세요
- **`ID` 칸은 고치거나 지우지 마세요.** 응답과 문항을 연결하는 값입니다. (회색 칸)
- **문구·보기 글자 수정은 언제든 괜찮습니다.** 단, 응답을 받기 시작한 뒤에 **보기 문구를 바꾸면** 이전 응답과 새 응답이 서로 다른 값으로 집계됩니다. 응답 시작 전에 확정하세요.
- **응답을 받기 시작한 뒤 질문을 삭제하면** 그 질문의 열이 결과에서 사라집니다. 가능하면 삭제하지 마세요.
- 줄 순서를 바꾸거나 새 줄을 추가해도 기존 응답은 그대로 유지됩니다. 문항이 바뀌면 `응답` 탭의 열 구성이 다음 응답이 들어올 때 자동으로 다시 만들어집니다. (③ 버튼으로 바로 갱신할 수도 있습니다.)
- `응답` 탭과 `원본` 탭은 직접 고치지 마세요. (`원본` 탭은 숨김 상태입니다.)

---

### 이전 형식 시트를 쓰고 있다면
시트 형식이 바뀐 버전(안내문구 항목당 한 칸, 보기 한 칸, 소제목당 한 칸)으로 업데이트할 때는 새 `Code.gs`, `Seed.gs`, `Index.html`을 붙여넣고 저장한 뒤, **설문 관리 → ① 샘플 문항 불러오기**를 다시 실행하세요.
- 시트의 문항·안내문이 **새 형식의 샘플로 덮어쓰이므로**, 고친 내용이 있으면 먼저 복사해 두세요.
- **이미 받은 응답은 그대로 유지됩니다.** (문항 ID가 같습니다.)
- 업데이트 직후 ①을 실행하기 전에는 설문 화면에 "설문을 준비하고 있습니다"가 나옵니다.

## 4. 결과 보기
- `응답` 탭: 응답자 1명 = 1행, 문항 = 열입니다. 이메일은 저장되지 않습니다. 피벗 테이블·필터·차트를 그대로 쓸 수 있습니다.
- `원본` 탭(숨김): 중복 응답 방지와 이어 쓰기용입니다. 이메일의 암호화 값이 들어 있어 **공유하지 마세요.**

## 5. 시험하기
1. 배포 후 본인 계정으로 웹 앱 URL을 열어 끝까지 응답해 보세요.
2. 시트 `응답` 탭에 1행이 쌓이면 정상입니다.
3. 다시 열면 "이미 제출하신 응답이 있습니다" 화면이 나옵니다.
4. 시험 응답은 `원본` 탭(숨김 해제 후)과 `응답` 탭에서 **같은 번호의 행**을 삭제하면 지워집니다.

## 6. 로그인 동작
- **학교 계정(`yonsei.ac.kr`, 하위 도메인 포함)으로 열면 로그인 화면 없이 바로 설문이 나옵니다.**
- **학교 계정이 아닌 경우에만** 로그인 안내 화면이 나옵니다.
- 한 브라우저에 구글 계정이 여러 개 로그인되어 있으면 구글이 **첫 번째 계정으로** 링크를 엽니다. 첫 번째가 개인 계정이면 안내 화면이 나오니, 그때 아래 방법으로 학교 계정을 고르세요. (구글 정책상 설문이 계정을 몰래 바꿔 줄 수는 없습니다.)

### 로그인이 잘못됐을 때 (개인 계정으로 열었을 때)
- 학교 계정이 아닌 계정으로 열면 **"학교 구글 계정으로 로그인해 주세요"** 화면이 나옵니다. 문항은 보이지 않습니다.
- 화면의 **다른 구글 계정으로 로그인** 버튼을 누르면 구글 계정 선택 화면으로 이동합니다. 학교 계정(@yonsei.ac.kr)을 고르거나 "다른 계정 사용"으로 로그인하면 설문이 열립니다.
- 버튼이 동작하지 않으면 구글 화면 오른쪽 위 프로필 → 다른 계정 추가로 학교 계정을 로그인한 뒤 링크를 다시 열거나, 시크릿(비공개) 창에서 링크를 열어 학교 계정으로만 로그인하세요.
- 구글이 직접 보여 주는 차단 화면("파일을 열 수 없습니다" 등)이 나온다면 배포의 **액세스 권한이 있는 사용자**가 "yonsei.ac.kr 내 사용자"로 되어 있는 것입니다. **배포 → 배포 관리 → 연필 아이콘**에서 **Google 계정이 있는 모든 사용자**로 바꾸고 **새 버전**으로 배포하세요.

## 7. 알아둘 점
- 본인 인증은 구글이 합니다. **`yonsei.ac.kr` 계정(하위 도메인 포함)만** 응답이 저장됩니다.
- 학교 구글 관리자가 외부 앱 배포를 막아 둔 경우 배포가 안 될 수 있습니다. 그때는 관리자에게 Apps Script 웹 앱 사용 허용을 요청하세요.
- 시트에는 이메일이 없지만, 설문을 배포한 담당자가 이메일 목록을 알고 있으면 해시를 계산해 응답자를 특정할 수는 있습니다. "익명 보장" 문구를 쓰실 때 참고하세요.
- **코드(`Code.gs`, `Index.html`)를 고친 경우에만** **배포 → 배포 관리 → 연필 아이콘 → 버전: 새 버전 → 배포**를 해야 반영됩니다. 시트 문구 수정에는 필요 없습니다.
- 동시에 응답이 몰려도 문항 설정은 5분 동안 캐시되어 시트를 매번 읽지 않습니다.
- 이 폴더의 설문은 claude.ai 링크의 설문과 별개이며, 응답 데이터는 서로 연동되지 않습니다.

## 8. 오류가 날 때
- **"Index(이)라는 이름의 HTML 파일을 찾을 수 없습니다"**
  1. Apps Script 왼쪽 파일 목록에 `Index` 파일이 **HTML 파일**로 있는지 확인하세요. 이름 옆에 `Index.html`로 보이는 것이 정상입니다. `Index.gs`(스크립트)이거나, 이름이 `Index.html.html`, `Untitled`, 앞뒤 공백이 있으면 안 됩니다.
  2. 이름이 잘못됐다면 파일 이름 옆 점 세 개(⋮) → **이름 바꾸기**로 `Index`(확장자 없이)로 고치세요. 파일 종류가 스크립트(.gs)라면 지우고 **+ → HTML**로 다시 만들어 내용을 붙여넣으세요.
  3. 파일을 고치거나 새로 만든 뒤에는 **저장**하고, **배포 → 배포 관리 → 연필 아이콘 → 버전: 새 버전 → 배포**를 해야 링크에 반영됩니다. (파일을 추가하기 전에 만든 배포는 옛날 버전을 계속 보여 줍니다.)
  4. 최신 `Code.gs`를 붙여넣으면 `index`, `Index.html` 같은 이름 변형은 자동으로 찾고, 그래도 없으면 위 내용을 알려 주는 화면이 나옵니다.
