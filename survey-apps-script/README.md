# 교내 연구진흥사업 만족도 설문 (Google 계정 로그인 버전)

학교 Google 계정으로 로그인한 사람만 응답할 수 있고, 응답은 구글 시트에 쌓입니다.
파일은 2개입니다. `Code.gs`(서버), `Index.html`(설문 화면).

## 설치 (약 10분, 담당자 1명이 한 번만)

1. **학교 Google 계정**으로 새 구글 시트를 만듭니다. 이름 예: `만족도 설문 응답`
2. 시트 메뉴에서 **확장 프로그램 → Apps Script**를 엽니다.
3. 기본으로 있는 `Code.gs`의 내용을 모두 지우고 이 폴더의 `Code.gs` 내용을 붙여넣습니다.
   - 응답 허용 도메인은 `yonsei.ac.kr` 로 이미 설정되어 있습니다. 다른 도메인(예: 하위 도메인 메일)도 허용하려면 `ALLOWED_DOMAINS` 목록에 추가하세요.
4. 왼쪽 파일 목록의 **+ → HTML**을 눌러 이름을 `Index`로 만들고(.html은 자동), 기본 내용을 지운 뒤 이 폴더의 `Index.html` 내용을 붙여넣습니다.
5. 오른쪽 위 **배포 → 새 배포**를 누릅니다.
   - 유형 선택(톱니바퀴): **웹 앱**
   - **다음 사용자 인증정보로 실행: 나**
   - **액세스 권한이 있는 사용자: ○○대학교(학교 도메인) 내 모든 사용자**
   - **배포**를 누르고, 권한 승인 창이 뜨면 본인 계정으로 허용합니다. (스프레드시트 접근 권한)
6. 나오는 **웹 앱 URL**이 응답자에게 보낼 설문 링크입니다.

## 링크를 두 가지로 나눠 쓰기
- **응답자(전임교원)**: 웹 앱 URL만 공유합니다. 시트 접근 권한은 필요 없습니다.
- **편집자·소유자**: 구글 시트를 공유(편집자 또는 보기 권한)합니다. 결과는 시트의 **`응답`** 탭에서 봅니다. 구글 드라이브에서 바로 열립니다.

## 결과 보기
- `응답` 탭: 응답자 1명 = 1행, 문항 = 열. 이메일은 저장되지 않습니다. 피벗 테이블, 필터, 차트를 그대로 쓸 수 있습니다.
- `원본` 탭: 중복 응답 방지와 이어 쓰기용입니다. 이메일의 암호화 값과 응답 원문이 들어 있어 **숨김 상태 그대로 두고 편집자에게 공유하지 마세요.**

## 동작 규칙
- 한 계정당 응답 1건입니다. 같은 계정이 다시 제출하면 새 행이 생기지 않고 기존 행이 수정됩니다.
- 중간에 나가도 다음에 열면 이어서 작성합니다.
- 공통질문 → 사업 선택 → 선택한 사업별 질문 → 마무리 공통문항 순서입니다.

## 문항·문구 수정
`Index.html` 안의 `설문 내용` 주석 구간(공통질문, 사업 안내문, 사업별 질문, 마무리 질문)만 고치면 됩니다.
수정 후에는 **배포 → 배포 관리 → 연필 아이콘 → 버전: 새 버전 → 배포**를 해야 링크에 반영됩니다. (링크 주소는 그대로입니다.)
문항 구조(문항 수나 순서)를 바꾸면 `응답` 탭의 열 구성이 달라지므로, 응답을 받기 시작한 뒤에는 바꾸지 않는 것을 권합니다.

## 시험
1. 배포 후 본인 계정으로 웹 앱 URL을 열어 끝까지 응답해 보세요.
2. 시트에 `응답`, `원본` 탭이 생기고 `응답` 탭에 1행이 쌓이면 정상입니다.
3. 다시 열면 "이미 제출하신 응답이 있습니다" 화면이 나와야 합니다.
4. 시험 응답은 `응답` 탭의 해당 행과 `원본` 탭의 해당 행을 삭제하면 됩니다. (같은 번호의 행이 서로 짝입니다.)

## 알아둘 점
- 본인 인증은 구글이 합니다. 학교 도메인 사용자는 웹 앱을 열 때 로그인 화면이 나오고, 이메일 주소로 응답자를 구분합니다.
- **같은 학교 도메인 사용자만** 이메일을 확인할 수 있어서, 학교 도메인 외 계정은 응답이 저장되지 않습니다. (설정이 "도메인 내 모든 사용자"일 때)
- 학교 구글 관리자가 외부 앱 배포를 막아 둔 경우 배포가 안 될 수 있습니다. 그때는 학교 구글 워크스페이스 관리자에게 Apps Script 웹 앱 사용 허용을 요청하세요.
- 시트에는 이메일이 없지만, 설문을 배포한 담당자는 이메일 목록을 알고 있으면 해시를 계산해 응답자를 특정할 수 있습니다. "익명 보장" 문구를 쓰실 때 참고하세요.
- 이 폴더의 설문은 claude.ai 링크의 설문과 별개입니다. 응답 데이터는 서로 연동되지 않습니다.
